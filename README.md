# Ninja-Streams
This page features AIOStreams templates and AIOMetadata configs for your perfect all-in-one stremio setup.

## AIOStreams:
### How to use:

Import the following config: [Ninja Streams Config](https://raw.githubusercontent.com/RandomNinjaAtk/Ninja-Streams/main/AIOStreams-Config/ninja-streams-config.json) using the AIOStreams Backup Feature.

### Steps
1. Download the config (right click link and save as): [Ninja Streams Config](https://raw.githubusercontent.com/RandomNinjaAtk/Ninja-Streams/main/AIOStreams-Config/ninja-streams-config.json)
2. In AIOStreams, navigate to  the "Save & Install" page
3. Under "Backups", select/click "Import"
4. Select/Click "Import Config"
5. Select the downloaded config file
6. Complete any remaining configurations and "save" or "create"





## AIOMetadata:
### How to use:
Import the following config: [Ninja Streams AIOMetadata Full Config](https://github.com/RandomNinjaAtk/Ninja-Streams/blob/main/AIOMetadata/ninja-streams-aiometadata-full-config.json) using the AIOMetadata Import Configuration feature.

### Steps
1. Download the config (right click link and save as): [Ninja Streams AIOMetadata Full Config](https://raw.githubusercontent.com/RandomNinjaAtk/Ninja-Streams/refs/heads/main/AIOMetadata/ninja-streams-aiometadata-full-config.json)
2. In AIOMetadata, navigate to the "Configuration" page
3. Under "Import Configuration", select/click "Import Configuration"
4. Select the downloaded config file
